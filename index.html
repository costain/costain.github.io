01 Java · Eclipse JDT
Cytoscape.js · Neo4j

Comprendia: AI-augmented code comprehension

Shipped a public Eclipse plugin that explains code from the dependency graph, not from embeddings.

Five layers: a Cytoscape.js graph UI, a JDT AST engine, OSV.dev and JGit vulnerability overlays, and an AiGateway across Claude, OpenAI, and Ollama. Graph-Aware Callee Pruning (GACP) keeps prompts on the live call graph with an O(V+E) reachability filter, so the output stays deterministic and reproducible across model families. Benchmarked on 6 fixtures × 4 prompt modes × 3 LLM families. Tool demo at ICSME 2026.

02 Python · DuckDB
Neo4j · Parquet

Ecosystem-scale mining pipelines

Two batch systems, and the findings they made possible.

A DuckDB pipeline modeled 33,596 agent-authored pull requests across 2,807 repositories, 1,797 developers, and 5 coding agents. Reviewer engagement was the strongest predictor of a merge. The overall merge rate was 71.5%, checked against qualitative coding of 60 pull requests. A Neo4j pipeline queried 14,459,139 Maven releases (658,078 artifacts), a 21-hour job on a 64GB, 24-core machine. Of the latest 635,000 releases, 62.89% carry a transitive vulnerability, against 31.39% with a direct one, and four CWEs are uniquely dangerous to Maven relative to MITRE's Top 25. Published at MSR 2026 and MSR 2025.
