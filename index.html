Selected Projects

Comprendia — AI-Augmented Code Comprehension
Eclipse IDE plugin · Java · 5-layer architecture
Zenodo Artifact Demo Video

Designed and shipped a 5-layer IDE plugin combining a Cytoscape.js dependency-graph UI, a JDT AST analysis engine, OSV.dev/JGit vulnerability integration, and an AiGateway spanning three production LLM backends (Claude, OpenAI, Ollama). Introduces Graph-Aware Callee Pruning (GACP), an algorithm that grounds LLM prompts in a live dependency graph instead of embedding similarity — producing deterministic, auditable output reproducible across LLM families via an O(V+E) reachability filter. Benchmarked across 6 code fixtures × 4 prompt modes × 3 LLM families. Tool demo accepted at ICSME 2026.

Built a 5-script scraping/HTML-parsing pipeline against the live Chromium issue tracker, working around its 1,000-record API cap to assemble a complete research dataset.
